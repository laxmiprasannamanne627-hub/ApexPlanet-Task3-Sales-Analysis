# ApexPlanet Task 3 – Sales Performance Analysis

## Project Overview
This project focuses on deep-dive sales performance analysis using Python and Power BI as part of the ApexPlanet 60 Days Data Analytics Internship.

## Objectives
- Analyse overall sales performance.
- Identify high-performing product categories.
- Compare sales across cities.
- Understand product-wise performance.
- Analyse customer purchasing patterns.
- Identify monthly sales trends.
- Develop business insights and recommendations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Microsoft Power BI

## Project Files
- Google Colab notebook
- Power BI dashboard
- Cleaned sales dataset
- KPI summary
- Category-wise analysis
- City-wise analysis
- Product-wise analysis
- Monthly sales analysis

## Key Findings
- Highest revenue category: Electronics.
- Highest sales city: Patna.
- Highest-performing product: Laptop.
- Highest sales month: March 2025.
- Total unique orders: 992.
- Total unique customers: 947.

## Conclusion
This project demonstrates data cleaning, exploratory data analysis, KPI development, visualization, dashboard creation and business insight generation.
